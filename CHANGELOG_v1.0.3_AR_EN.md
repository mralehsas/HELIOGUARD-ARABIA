# HELIOGUARD ARABIA v1.0.3 — Disconnected Start

## العربية
- يبدأ البرنامج بحالة **غير متصل** دون إرسال طلبات تلقائية إلى NASA أو NOAA.
- يبدأ الاتصال فقط بعد الضغط على **اتصال حي**.
- بعد أول اتصال ناجح يتحول الزر إلى **تحديث حي** ويبدأ التحديث الدوري كل خمس دقائق.
- الحالة الابتدائية محايدة باللون الرمادي وليست فشلًا أو تحميلًا.
- لا تُستخدم نتائج تشخيص محفوظة لإظهار البرنامج متصلًا عند بدء التشغيل.
- مركز الاتصالات يحتفظ بتشخيصه منفصلًا عن حالة المصادر التشغيلية الثمانية.
- تدقيق التحويل بين العربية RTL والإنجليزية LTR في حالة عدم الاتصال وبعد بدء الاتصال.

## English
- The application starts in a neutral **Disconnected** state without sending automatic NASA or NOAA requests.
- Network activity begins only after pressing **Connect Live**.
- After the first connection, the button becomes **Live Update**, and the five-minute refresh cycle begins.
- Stored diagnostic results no longer make the main dashboard appear connected at startup.
- Arabic RTL and English LTR switching was verified in both disconnected and active states.
