# HELIOGUARD ARABIA v1.0.1 — تصحيح الواجهة الرسمي المعتمد

## التشغيل
1. فك الضغط كاملًا.
2. شغّل `START_HELIOGUARD.bat`.
3. اترك نافذة الخادم مفتوحة.
4. يفتح البرنامج على `http://127.0.0.1:8080/index.html`.
5. استخدم زر `EN` أو `AR` لتبديل لغة الواجهة.
